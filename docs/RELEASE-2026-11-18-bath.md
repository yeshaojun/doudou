# 洗香香与看得见的长大

“照顾”抽屉增加洗澡入口，保持原来的四分类，不扩长首页菜单。洗澡有四个需要亲手完成的阶段：拿花洒淋湿身体、用香皂来回搓泡泡、拿花洒冲净、离开澡盆到干软垫上用毛巾擦干。下一工具逐步解锁，换步骤时清掉指针捕获并归位旧工具，防止道具重叠挡住触摸。脸和耳朵不计清洗进度；松手、取消、切后台、离开场景都停水。

成长扩展为实际体型变化，主猫以脚为锚点从0.68、0.76、0.84到0.94渐变，保留眼睛跟随、抚摸、走动与睡眠引擎。阶段为奶猫、小猫、少年猫、大猫；成长时返回房间伸懒腰，成长册使用四种大小的猫咪图形与进度条。

首次亲手完成一种故事得3点；首次完成吃饭、安睡至少12秒、刷牙漱口、叠被得2点；换着练习、不在最近3种内的重复行为得1点。成长阶段阈值为0、6、15、24，累计上限60。没有日期门槛、掉级、死亡或离线扣分。只开始动作、拿起道具、未做完、自动帮忙都不奖励。旧版故事存档按每种3点迁移，新增成长经验、最近练习和照顾经历随家长存档导入导出，JSON字段均有类型、范围和允许值校验。
